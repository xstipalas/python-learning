- int(число, СС) переводит число из любой системы в десятичную
- bin(число) переводит число в двоичную систему счисления
- list.insert(индекс, элемент) ставит элемент на указанный индекс, сдвигая остальные
- list.pop(индекс) удаляет и возвращает элемент списка по индексу
- itertools.product(*итераторы) создает список со всевозможными комбинациями элементов всех итераторов
- ord(символ) возвращает код символа из ASCII.
- chr(код) возвращает символ указанного кода из ASCII
