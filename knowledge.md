# Шпаргалка по Python

## 🔢 Работа с числами и системами счисления
- `int(строка, основание)` — переводит число из указанной системы счисления (2-36) в десятичную
- `bin(число)` — переводит число в двоичную систему счисления (возвращает строку с префиксом '0b')
- `hex(число)` — переводит число в шестнадцатеричную систему (префикс '0x')
- Проверка четности: `число & 1` (быстрее, чем `число % 2`)
- Форматирование с выравниванием: `f'{число:>5}'` — выравнивание по правому краю до 5 символов (см. раздел о строках)

## 📋 Списки и операции с ними
- `list.insert(индекс, элемент)` — вставляет элемент на указанный индекс, сдвигая остальные вправо
- `list.pop(индекс)` — удаляет и возвращает элемент списка по индексу (без аргумента удаляет последний)
- `list.index(элемент)` — возвращает индекс первого вхождения элемента (ValueError, если элемент не найден)
- `list.count(элемент)` — возвращает количество вхождений элемента в список
- `список.sort()` — сортирует список на месте (O(n log n), память O(1) для Timsort в Python)
- `sorted(список)` — возвращает новый отсортированный список
- Среднее значение: `sum(список) / len(список)` (осторожно с пустым списком)
- Для поиска n минимальных/максимальных элементов: `heapq.nsmallest(n, список)` или `heapq.nlargest(n, список)` (эффективнее полной сортировки)

## 🔍 Поиск уникальных элементов
- **Поиск уникального элемента в массиве, где все остальные имеют дубликаты:** сравнение первых трёх элементов для определения эталона, затем поиск отличий
- **XOR-метод** (когда все числа кроме одного встречаются четное количество раз, включая пары):
  ```python
  уникальное = 0
  for число in список:
      уникальное ^= число
  ```

## 🧵 Строки и символы
- `ord(символ)` — возвращает Unicode код символа
- `chr(код)` — возвращает символ по Unicode коду
- `строка.isdigit()` — проверяет, состоит ли строка только из цифр (не пустая)
- `f'{переменная!r}'` — добавляет кавычки при выводе строки (repr-представление)
- `f'{переменная:^10}'` — выравнивание по центру до 10 символов с добавлением пробелов
- `str.capitalize()` — возвращает строку с первым символом в верхнем регистре, остальными в нижнем
- `строка.find(подстрока)` — возвращает индекс первого вхождения или -1 (в отличие от index(), который бросает исключение)
- `строка.replace(что, на_что, количество_замен)` — заменяет подстроки (возвращает новую строку)

## 📚 Словари и множества
- `dict(zip(список_ключей, список_значений))` — создает словарь из двух списков
- `множество1.issubset(множество2)` — проверка, является ли множество1 подмножеством множества2
- `множество1.issuperset(множество2)` — проверка, является ли множество1 надмножеством множества2
- `str.maketrans(x, y, z)` + `строка.translate(таблица)` — создание и применение таблицы замены символов

## 🧩 Модули и инструменты
- `itertools.product(*итераторы, repeat=1)` — декартово произведение (все возможные комбинации)
- `re.sub(шаблон, замена, строка, count=0)` — заменяет все вхождения шаблона в строке
- `r'\D'` в `re.sub()` — заменяет все символы, кроме цифр (инвертированный класс `\D` = не цифра)
- `dataclasses` — модуль для быстрого создания классов-хранилищ (декоратор `@dataclass`)
- `traceback.extract_stack()` — получение информации о текущем стеке вызовов (`.lineno` не существует напрямую, используйте `inspect.currentframe().f_lineno`)

## 🏷️ ООП (Объектно-ориентированное программирование)
- **Статические методы** (`@staticmethod`) — методы, логически связанные с классом, но не получающие `self` или `cls`
- **Методы класса** (`@classmethod`) — методы, получающие класс (`cls`) вместо экземпляра (`self`)

## 📝 Продвинутые темы и советы
- **Датакласс** (`@dataclass`) — класс, основная задача которого — хранение данных (автоматически генерирует `__init__`, `__repr__`, `__eq__`)
- **Декоратор** — функция, принимающая другую функцию и возвращающая её модифицированную версию
- **List comprehension** (`[x for x in range(10)]`) — использовать, когда нужен готовый список для многократного доступа
- **Генератор** (`(x for x in range(10))`) — использовать, когда важна память и элементы нужны только один раз
- `n & (n << 1)` — проверка наличия двух идущих подряд единиц в битовой записи числа (результат != 0 → есть соседние единицы)
- `n & ~(n >> 1)` — выделение битов, которые являются началом группы единиц (полезно для подсчёта групп)
- Форматирование строк с выравниванием: `f'{переменная:<10}'` — выравнивание по левому краю, `f'{переменная:>10}'` — по правому, `f'{переменная:^10}'` — по центру, добавляя пробелы до длины 10
- Сумма первых n строк в треугольнике нечетных чисел: `n³` (например, 1 + 3 + 5 + 7 = 16 = 4³)
- **Тест Миллера-Рабина** — вероятностный алгоритм проверки большого числа на простоту (детерминирован для чисел < 2^64 с известными базами)
