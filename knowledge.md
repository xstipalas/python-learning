# Шпаргалка по Python

## 🔢 Работа с числами и системами счисления
- `int(число, СС)` — переводит число из любой системы счисления в десятичную
- `bin(число)` — переводит число в двоичную систему счисления
- Проверка четности: `число & 1` (быстрее, чем `% 2`)
- Форматирование: `f'{число1:число2}'` — добавляет перед числом1 столько чисел2, чтобы общая длина составляла число3

## 📋 Списки и операции с ними
- `list.insert(индекс, элемент)` — ставит элемент на указанный индекс, сдвигая остальные
- `list.pop(индекс)` — удаляет и возвращает элемент списка по индексу
- `list.index(элемент)` — возвращает первое вхождение элемента в список
- `list.count(элемент)` — возвращает количество вхождений элемента в список
- `список.sort()` — сортировка со скоростью O(n log n) и памятью O(n)
- Среднее значение: `sum(список) / len(список)`
- Для поиска n минимальных/максимальных элементов — отсортировать список и взять первые/последние n элементов

## 🔍 Поиск уникальных элементов
- **Лучший способ поиска уникального элемента** — сравнение 3-х первых элементов для нахождения эталона, затем сравнение эталона со всеми элементами
- **XOR-метод** (если у всех чисел кроме одного есть дубликат): `уникальное = 0; for число in список: уникальное ^= число`

## 🧵 Строки и символы
- `ord(символ)` — возвращает код символа из ASCII
- `chr(код)` — возвращает символ указанного кода из ASCII
- `строка.isdigit()` — проверяет, состоит ли строка из цифр
- `f'{переменная!r}'` — добавляет кавычки, если переменная содержит строку
- `f'{переменная: ^число}'` — возвращает строку с пробелами по краям до указанной длины
- `str.capitalize()` — возвращает строку с первым символом в верхнем регистре и остальными в нижнем
- `строка.find(подстрока)` — возвращает индекс первого вхождения подстроки или -1

## 📚 Словари и множества
- `dict(zip(список1, список2))` — создает словарь с ключами из список1 и значениями из список2
- `множество1.issubset(множество2)` / `множество1.issuperset(множество2)` — проверка подмножества/супермножества
- `str.maketrans()` + `строка.translate(таблица)` — создание и применение таблицы замены

## 🧩 Модули и инструменты
- **itertools.product(*итераторы)** — создает всевозможные комбинации элементов итераторов
- **re.sub(что, на_что, строка, число_замен)** — заменяет элементы строки
- `r'\D'` в `re.sub()` — заменяет все, кроме чисел
- **dataclasses** — модуль для быстрого создания классов-хранилищ
- **traceback.extract_stack().lineno** — номер текущей строки в файле (модуль traceback)

## 🏷️ ООП (Объектно-ориентированное программирование)
- **Статические методы** — методы, логически связанные с классом, но не нуждающиеся в нем
- **Методы класса** — методы, обращающиеся напрямую к классу

Последнее:
- Датакласс - класс, задача которого - хранение данных
- Декоратор - функция, принимающая и возвращающая функцию
- list comprehension лучше использовать, когда нужен готовый список с его возможностями
- Генератор лучше использовать, когда важна память и нужно пройтись по каждому элементу один раз
- n & (n << 1), где n - число, позволяет проверить битовую строку на наличие подряд идущих единиц
- n & ~(n >> 1), где n - число, позволяет проверить битовую строку на количество отдельных групп единиц
- f{переменная: знакчисло}, где знак - <, > или ^, выравнивает строку по левому, правому краю или по центру, добавляя проблеы так, чтобы общая длина составляла указанное число
