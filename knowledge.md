- int(число, СС) переводит число из любой системы в десятичную
- bin(число) переводит число в двоичную систему счисления
- list.insert(индекс, элемент) ставит элемент на указанный индекс, сдвигая остальные
- list.pop(индекс) удаляет и возвращает элемент списка по индексу
- itertools.product(*итераторы) создает список со всевозможными комбинациями элементов всех итераторов
- ord(символ) возвращает код символа из ASCII.
- chr(код) возвращает символ указанного кода из ASCII
- сортировка с помощью список.sort() происходит со скоростью O(nlogn) и памятью O(n)
- строка.isdigit() проверяет, состоит ли строка из цифр
- dict(zip(список1, список2)) создает словарь с ключами из элементов списка1 и значениями из списка2
- re.sub(строка которую заменяем, строка на которую заменяем, строка в которой заменяем, число замен) заменяет элементы строки.
- r'\D' в re.sub() заменяет все, кроме чисел
- список.index(элемент) возвращае первое вхождение элемента в список
- f{переменная!r} добавляет кавычки, если переменная содержит строку
- список.count(элемент) возвращает количество вхождения элемента в список
- среднее значение элементов списка можно находится следующей формулой: sum(список) / len(список)
- лучший способ поиска уникального элемента в списке - сравнение 3-х первых элементов и нахождение эталона, затем - сравнение эталона со всеми элементами списка
- если нужны n минимальных/максимальных элементов списка, можно отсортировать его и взять первые/последние n элементов
- множество1.issubset(множество2)/множество1.issuperset(множество2) проверяет, является ли множество1 подмножеством/супермножеством множества2
